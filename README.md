
# 💰 Investment Profit Predictor

A Machine Learning web application that estimates business profit based on investment details. Built using Python, Scikit-learn, Pandas, and Streamlit.

## 📌 Project Overview

This project demonstrates how Machine Learning can be used to predict estimated profit from investment-related inputs through a simple interactive web interface.

## ✨ Features

- Enter Research and Development investment.
- Enter Administration expenses.
- Enter Marketing investment.
- Select a state.
- Generate a predicted profit using a trained ML model.
- Interact with the application through a Streamlit interface.

## 🛠️ Technologies Used

- Python
- Pandas
- Scikit-learn
- Streamlit
- Pickle
- Git and GitHub

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/yashwanth86868/Investment-Profit-Predictor-SLR.git
cd Investment-Profit-Predictor-SLR
```

### 2. Create a virtual environment

```bash
python -m venv .venv
```

Activate it on Windows:

```powershell
.venv\Scripts\Activate.ps1
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the application

Ensure the trained model file `model.pkl` exists in the project folder. If necessary, run the training script to generate it.

```bash
streamlit run app.py
```

## 🧠 How It Works

1. The user enters investment details.
2. The application prepares the input features.
3. The trained Machine Learning model predicts the estimated profit.
4. The result is displayed on the Streamlit webpage.
